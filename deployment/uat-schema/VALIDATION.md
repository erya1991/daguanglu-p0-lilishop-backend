## 已发现并修正的部署差异

- Linux 小程序构建找不到注入的 Sass 相对路径，改为共享主题别名，两端重建通过。
- 旧菜单引导与新增住户目录的顺序冲突，改为先建立基础目录、再安装住户菜单并完成首次管理员授权。
- 初始化中 BIT 值需保持数值类型，不能按普通文本编码。
- Docker Desktop 的配置挂载权限导致 MySQL 忽略选项文件，容器内命令改为使用临时私有选项文件。
- Linux Redis 默认入口会切换用户，无法读取 600 权限的配置；使用明确入口和受控容器用户，保持私有配置权限。
